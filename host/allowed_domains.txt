# =============================================================================
# Egress allowlist. One domain per line. Leading dot = domain AND subdomains.
#
# Keep minimal: every entry is a capability grant, not just a destination.
# To find missing domains:   ptrbox logs --denied
# After editing:             squid -k reconfigure
#   (reloads without dropping tunnels; a full restart severs every live VM
#   connection, including Claude's in-flight request)
#
# `ptrbox install` copies this file in only if none exists yet - once
# installed, the live allowlist is yours to curate and install will report a
# diff rather than overwrite it.
#
# Scope: the proxy is shared by every VM and cannot tell them apart (Lima's
# usernet relay makes all guests look like 127.0.0.1), so a domain added here
# is granted to ALL sandboxes. There is no per-project allowlist.
# =============================================================================
